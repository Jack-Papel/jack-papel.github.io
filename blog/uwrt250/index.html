The Archive (UWRT-250)

For Advanced Writing Seminar, a class I took at RIT about writing in one's discipline, the final project was to create a website detailing our semester's work. This is that site—a collection of articles about writing in software development, my experience in the class, and more.

Abstract

This project is a website for exploring how writing is used in software development. It includes two major essays about what it means to write in software development. The first covers its role as a fundamental aspect of the discipline: how it impels us to write understandable code; the use of multimodal communication to express ideas (particularly via code comments); the importance of code review and feedback; and how AI affects the role writing plays without reducing its importance. The second is an auxiliary piece which covers the role writing takes on in a development team specifically, and how that differs from software development as a whole: how it constitutes dev teams; its use to facilitate and define collaboration within a team, how identity and power is constructed through writing; and more. Much like the first essay, it also talks about how AI affects writing's role in a dev team, and how its effects on the structure of a development team are much more substantial. It also contains journal entries and artifacts which document my experience in the class and reflect on the creation of the projects and what I learned.

Design Statement

I intend for this project, as well as all of my blog posts, to be as accessible as possible. Some design considerations I've made for accessbility include:

  • Accessible colors
  • Navbar for easy navigation
  • "Skip to Content" button for keyboard users
  • Alt text for all images

See the Extended Design Statement for more details on how this site was designed for accessibility and inclusivity.
